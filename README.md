# 安装
1. 把项目在codex中打开并安装skill
2. 用skill执行准备开始
3. 在项目根目录有个OB-Task-Doc/OBFigma.md文件
4. 在OBFigma.md里边列出任务列表

# 开始前的准备
做以下简单初始化，运行一下Demo页面，适配一下OB风格。完成以后就可以在OBFigma.md文件中列出任务开始执行了。

## 资源(可选)
1. 要先把check_select/normal图片导出
2. back按钮图片

## base Cell(推荐)
1. 针对普通列表页面 icon title check做简单的初始化
2. isSelected中实现baseView的背景颜色、边框等效果
3. 选中cell的背景效果要在selectedBaseView中实现

## base View(推荐)

1. 下一步按钮初始化和布局
2. 背景颜色
3. 背景图布局和图片
